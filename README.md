# Ali Raza — portfolio website

This is a static HTML/CSS/JavaScript portfolio based on the uploaded `index.html`. It keeps the existing page as the homepage and adds separate pages for About, Data Entry Services, Web Development Services, Portfolio, and Contact.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server. No build step or package install is required. The site is intended for static hosting such as Netlify.

## Files

- `index.html` — existing homepage, updated to feature both service categories
- `about.html`
- `data-entry.html`
- `web-development.html`
- `portfolio.html`
- `contact.html`
- `portfolio-pages.css` and `portfolio-pages.js` — shared styles and small navigation/contact-form behavior for the new pages

The website inquiry form opens the visitor's email application with a prefilled message. It does not send or store form submissions on a server.

## Existing image assets

The uploaded source contained references to these existing portfolio images, but the image files themselves were not included: `5.png`, `lead-gen.png`, `data-entry.png`, `market.png`, `email-collection.png`, and `crm.png`. Keep those files beside `index.html` when deploying if you want the original homepage portfolio/proof images to display.
